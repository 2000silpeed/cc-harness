# 동작을 유지하며 정리

`docs/lessons/09-13-tdd.md`의 12강을 읽는다.

1. 현재 Green·AC 결과와 검사 대상 변경이 일치하는지 확인한다.
2. 중복, 이름의 명확성, 단일 책임, 불필요한 복잡도, AGENTS 규칙 일치의 다섯 기준으로 후보를 고른다.
3. 가치 있는 작은 변경 하나를 적용하고 관련 테스트를 확인한다.
4. 회귀가 나면 자신의 마지막 변경을 되돌리거나 수정한다. 사용자 작업을 reset/checkout으로 지우지 않는다.
5. 동작 변경·새 기능·계약 변경이 필요하면 Refactor로 숨기지 않고 시나리오/Red로 돌린다.
6. 전후 차이·테스트 결과를 남기고 security-review로 인계한다. 개선할 이유가 없으면 변경 없음으로 종료해도 된다.

테스트를 느슨하게 하거나 억지 공통 추상화를 만드는 작업은 하지 않는다.
