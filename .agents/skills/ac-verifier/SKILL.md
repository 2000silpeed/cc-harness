# AC 독립 검토 계약

`docs/methods/tdd.md`의 `### AC 검증 기록` 절만 읽는다(다음 같은/상위 수준 제목 직전까지). 입력은 이슈 AC 원문·PRD·변경 코드·실제 실행 증거다.

1. 구현자의 완료 설명 대신 AC를 먼저 읽고 필요한 관찰을 정의한다.
2. 각 AC를 구현 경로와 테스트/실행 증거에 대응시킨다. 없는 증거는 unverified로 둔다.
3. 테스트가 관찰해야 할 의미, 잘못된 기대값, 빠진 경계·권한·오류 상태를 독립적으로 검토한다.
4. 안전하고 허용된 범위에서 직접 재현한다. 코드 수정 권한은 이 검토 역할에 포함하지 않는다.
5. AC별 pass/fail/unverified와 파일·실행 근거·다음 행동을 기록한다.
6. 누락된 요구사항은 test-scenarios→tdd-red로, 단순 구현 결함은 실패 재현 후 Green으로 돌린다.

독립 서브에이전트가 허용되고 가능하면 이 SKILL.md와 원자료를 전달해 수행한다. 동일 에이전트의 재검토라면 그렇게 밝힌다. 독립 검토가 필수인 프로젝트에서는 대체 검토를 독립 pass로 기록하지 않는다. 사용자 최종 수락은 별도다.
