# 컴포넌트 기준

적용 대상은 기존 구조도 문서이며 PM 앱 컴포넌트가 아니다. 수치의 단일 기준은 같은 폴더의 colors.md, typography.md, spacing.md에 있다.

| 요소      | 구조·상태 기준                                                                        |
| --------- | ------------------------------------------------------------------------------------- |
| 헤더      | 눈썹 제목 → h1 → 보조 설명 → 줄바꿈 가능한 배지                                       |
| 배지      | 기본 외곽선과 경고 외곽선을 구분. 클릭 버튼이 아니므로 hover/disabled 상태는 없음     |
| 카드      | 둥근 모서리와 테두리, 소제목. 좁은 화면에서는 내부 여백 축소                          |
| 렌더 상태 | 기본 로딩 문구, success 성공 문구, error 오류·대체 경로 안내. 색만으로 의미 전달 금지 |
| 구조도    | Mermaid 렌더, 가로 스크롤. 실패해도 원문을 읽을 수 있어야 함                          |
| 표        | 헤더 강조, 행 구분선, 긴 파일 경로 줄바꿈. 좁은 화면은 가로 스크롤                    |
| 링크·접기 | 키보드 focus-visible 외곽선 유지. hover는 기존 브라우저 동작 유지, 새로운 효과 미정의 |
| 코드 원문 | monospace, 줄바꿈, 별도 배경. 접기 summary는 키보드로 조작 가능                       |

정적 검사는 컴포넌트의 존재·상태 전환·접근성·선택자별 값 배치를 보장하지 않는다. 해당 사항은 실제 화면에서 확인한다. 입력 폼, disabled 버튼, PM 간트차트의 디자인은 아직 정의하지 않았다.
