# PM 자동 실행 계약 · 2026-09-13

- 사용자 원문: “현재 변경을 검토해 로컬 기준 커밋하고, PM-03~PM-10 총 8개를 이슈별 최대 3회 수정하며 진행해. 푸시·배포는 제외해.”
- 대상: cc-harness, 현재 master의 검토된 PM-02 완료 상태를 로컬 기준 커밋으로 고정. 별도 브랜치·원격 작업 없음.
- 범위: PM-03 → PM-04 → PM-05 → PM-06 → PM-07 → PM-08 → PM-09 → PM-10, 최대 8개. 승인된 PRD·요구사항·기술안은 변경하지 않는다.
- 이슈별 Green 시도 최대 3회. 테스트 수정 시도·잘못된 Red·AC fail·회귀 실패·보안 high 잔존 등 tdd-auto-loop 원문 STOP을 유지한다. STOP이면 이후 이슈를 진행하지 않는다.
- 기술 계약·시나리오는 이 범위에서 위임 검토한다. 단계별 독립 agent 결과·실제 로그·검사 대상 버전을 보존한다. 공유 작업 트리의 파일 소유 범위를 나누며 OS 수준 파일시스템 격리를 주장하지 않는다.
- 허용: 로컬 파일·테스트용 격리 데이터·검증 및 로컬 인계 초안. 실제 사용자 데이터 삭제·교체, 원격 공개·푸시·배포·비용 발생은 수행하지 않는다.
- 기준 커밋 이후 이슈 결과는 별도 기록한다. 추가 Git 작업은 명시된 범위와 사전 점검을 따르며 무단으로 변경을 삭제·커밋하지 않는다.
