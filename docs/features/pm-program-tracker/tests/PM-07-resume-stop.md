# PM-07 재개 실행 중단 · 독립 AC 실패

> 아래의 커밋·푸시 여부는 이 PM 실행 종료 당시의 기록이다. 이후 하네스 문서 배포에 검수 기록을 포함하더라도 PM-07 구현 소스는 포함하지 않는다.

실행 ID `pm-resume-20260913`, 준비 기준 커밋 `ca79c7a`. 사용자가 승인한 PM-07–PM-10 최대 4개·이슈별 Green 최대 3회 실행은 PM-07 독립 AC 단계에서 중단했다. 이전 실행의 fixture STOP과 별도 이력이다.

## 완료한 단계

- 수정 테스트 독립 검토 → 준비 보완 → 독립 재검토 통과. 미구현 테스트 포함 준비 기준점을 로컬 커밋했다. 훅 통과, 푸시 없음.
- 새 Red: 단위 83개 중 미구현 assertion 71개 실패·정상 허용 no-op 12개 통과. fixture/import 실패 없음. 브라우저 5개는 Excel UI 미구현으로 실패했다.
- Green 1회차는 입력 바이트 불변성 1건 실패. SheetJS에 입력 복사본을 전달한 2회차에서 대상 83개·전체 단위 240개 통과. 동결 테스트 4개 해시 불변. 에이전트 로그 이름의 `attempt1`과 달리 실제 수정 횟수는 **2회**로 계산한다.
- 현재 빌드로 브라우저 5개 통과. 메인의 첫 브라우저 검사는 agent의 임시 빌드가 아닌 오래된 dist를 사용해 실패했다. 이를 현재 구현 실패로 잘못 보고하지 않고 `tmp/pm-resume-07-green-browser.log`에 보존했다. 현재 빌드 검증은 `tmp/pm-resume-07-green-browser-current.log`다.
- 별도 5175 임시 검수 환경에서 Excel 1행 미리보기·모바일 내부 스크롤·키보드 포커스·취소를 확인했다. `tmp/pm07-preview-desktop.png`, `tmp/pm07-preview-mobile.png`. 저장하지 않았고 임시 탭·서버는 종료했다. 사용자 최종 디자인 승인이나 Windows 검증은 아니다.

## 실제 중단 원인

적용 파일 `.agents/skills/tdd-auto-loop/SKILL.md` 원문: **“AC: 독립 결과 ac_passed=false 또는 증거 부족이면 STOP.”** 남은 Green 1회가 있어도 이 조건이 우선한다. [독립 AC 보고서](PM-07-resume-ac.json)의 두 재현 결과를 따른다.

1. `src/domain/program-excel.ts:44`: 캐시 값 없는 수식 `<c r="C2"><f>1+1</f></c>`을 SheetJS 읽기 단계가 누락한다. 후속 검사는 이를 빈 담당자로 받아들여 신규 1행·오류 0건으로 반환한다. 수식을 실행한 것은 아니지만, 수식이 있으면 위치·이유를 표시하고 거부해야 한다는 AC2 위반이다.
2. `src/domain/xlsx-zip.ts:49`: 정상 ZIP의 data descriptor 플래그(bit 3)를 거부한다. 동일 워크북을 표준 ZIP 스트리밍 방식으로 저장한 파일은 SheetJS에서 읽히지만 앱은 손상 파일로 거부해 AC1을 충족하지 않는다. 플래그만 허용하면 안 되며 descriptor의 크기·CRC·경계 검증까지 필요하다.

기존 단위·브라우저 통과는 이 두 사례를 검증하지 않는다. AC1·AC2 fail, AC3·AC4 pass이며 PM-07 완료로 표시하지 않는다. Refactor·보안 완료 판정과 PM-08–PM-10은 진행하지 않았다. 번들 500 kB 초과 경고도 남아 있다.

## 보존과 재개 입력

구현과 검수 기록은 `ca79c7a` 이후 미커밋 상태로 보존한다. 이미 요청한 준비 커밋과 미완료 구현을 혼동하지 않는다. 원본 5173·샘플 5174 서비스와 IndexedDB 데이터를 삭제·복원·교체하지 않았다. 빌드는 공용 dist를 갱신하지만 브라우저 저장 데이터에는 쓰지 않는다. 샘플 JSON은 tmp에 보존한다. 푸시·배포 없음.

다음 실행은 두 재현을 정식 시나리오·Red에 추가하고, 수식 존재 보존 및 descriptor 검증을 구현한 뒤 독립 AC를 다시 수행해야 한다. 기존 요구사항·테스트를 완화하지 않는다. 중단을 없었던 것으로 처리하거나 남은 이슈를 건너뛰지 않는다.
