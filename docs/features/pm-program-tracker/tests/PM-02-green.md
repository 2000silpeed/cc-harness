## 승인·구현 범위

PM-02 Red 결과 후 사용자 “구현하세요”. 저장된 프로그램의 정보·상태·날짜 수정과 취소·대상 전환을 구현했다. 삭제·간트·백업 등은 추가하지 않았다.

- createProgramEditDraft: 기존 9개 값 복사, null 날짜만 빈 문자열, 상태 보존.
- repository.update: 같은 id로 갱신. 존재·자기 제외 중복 확인·put을 하나의 readwrite 트랜잭션에서 처리, commit 후 성공. not-found/duplicate/storage 구분. 기존 DB 버전·인덱스 유지.
- App: 프로그램명으로 수정 진입, 편집 대상 선택, 변경 폐기 확인, 같은 id·목록 위치 유지, 오류·재시도·대상 소실 재조회. 저장 중 입력·취소·이동 차단. 닫기 후 대상 프로그램 버튼으로 포커스 복귀.
- 등록 폼·검증기를 재사용한다. 한 행 9열과 날짜별 — 표시를 유지하고 긴 프로그램명은 수정창에서 전체 문구로도 제공한다.
- 계약에 따라 기존 프로그램명 전체 보기 회귀만 수정 진입으로 이행했다. 다른 값 전체 보기 기능은 유지한다. 신규 테스트의 기대값은 완화하지 않았다.
