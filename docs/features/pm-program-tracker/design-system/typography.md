# PM 타이포그래피

상태: 디자인 제안. 합성기의 명시적 font_system 입력을 기준으로 하며 폰트 파일 다운로드나 브라우저 로드는 아직 하지 않았다.

| 역할         | 기준                             | 크기·행간·굵기                   | 사용                                    |
| ------------ | -------------------------------- | -------------------------------- | --------------------------------------- |
| 제목         | Inter + Noto Sans KR + system-ui | 24px / 1.4 / 600                 | 작업바의 짧은 제목, 거대한 display 제외 |
| 본문·행      | 동일 stack                       | --ds-text-md = 15px / 1.6 / 400  | 프로그램 목록·폼                        |
| 열 제목·라벨 | 동일 stack                       | --ds-text-sm = 13px / 1.45 / 600 | 한글 uppercase 변환 금지                |
| 보조 문구    | 동일 stack                       | --ds-text-sm = 13px / 1.6 / 400  | 일정 미정·설명                          |
| 식별 값      | --ds-font-mono + 한글 fallback   | 13px / 1.6 / 400                 | ZGWLEJ10000 등, 원문 대소문자 보존      |
| 날짜         | 본문 stack + tabular-nums        | 13–15px / 1.6 / 400              | YYYY-MM-DD, 예정·실제 라벨 생략 금지    |

`--ds-font-body`에는 Inter, `--ds-font-ko`에는 Noto Sans KR, `--ds-font-mono`에는 JetBrains Mono가 생성돼 있다. 구현 시 한글은 `font-family: Inter, "Noto Sans KR", system-ui, sans-serif` 순서로 연결한다. 생성 CSS 자체가 폰트를 내려받지는 않는다. 오프라인 제공 여부와 라이선스 확인 후 로컬 번들 또는 시스템 폰트 방식을 결정한다.

자동 생성 설명의 Pretendard 가이드는 범용 추천이므로 명시적 font_system을 덮어쓰지 않는다. 24px은 PM 제목용 저작 제안이며 생성된 30/37px 제목을 억지로 사용하지 않는다.

긴 프로그램명은 줄바꿈 또는 포커스 가능한 상세에서 전체 문자열을 확인하게 한다. hover tooltip만으로 전체 값 접근을 해결하지 않는다. 한글 본문은 자연스러운 줄바꿈, 영숫자 식별 값은 필요한 경우 overflow-wrap:anywhere를 허용한다. 날짜·열 숫자는 정렬하고 200% 확대 때 기능을 숨기지 않는다.

검증 상태: 토큰 이름·값 확인. 실제 폰트 로드, 한글 줄바꿈, 확대와 렌더링은 미검증.
