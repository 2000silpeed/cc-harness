# PM 프로그램 관리 도구 · 최초 요청

이 문서는 인터뷰가 진행된 뒤, 대화에 남아 있는 최초 요청과 입력 예시를 보존한 것이다. 이후의 결정은 [인터뷰 기록](interview.md)과 [요구사항 정의서](spec-fixed.md)에 구분해 기록한다.

## 사용자가 선택한 기능

> PM을 위한 프로젝트 관리 도구 (프로그램 목록, 진행상태 완료예정일 담당자 전체 타임스케줄 관리)

사용자가 직접 선택한 기능이다.

## 사용자가 제시한 등록 예시

> 모듈 = LE, 프로그램 명 = ZGWLEJ10000, 변경 유형 = ODATA 신규 개발, 개발완료 = 26년 07월 10일, 이관예정일 = 26년 9월 6일

추가 입력:

> 담당자 = 이성운

## 최초 입력에 없거나 모호했던 부분

- “개발완료”가 예정일인지 실제 완료일인지 구분되지 않았다.
- 개발 시작 예정일과 개발 완료 예정일은 제시되지 않았다.
- 진행 상태의 단계, 전체 일정의 표시 방식, 저장 환경과 중복 처리 기준은 아직 제시되지 않았다.
- 위 예시는 요구사항을 설명하는 입력이며, 실제 앱에 저장된 데이터나 구현 결과가 아니다.

## 근거 범위

- 사용자의 과제 요청 및 이어진 질문 1~11의 대화.
- 프로젝트의 `feature-planning-workflow.md` 중 단계 1: 요구사항 인터뷰.
- 다른 기능의 요구사항을 이 기능의 요구사항으로 복사하지 않는다.
