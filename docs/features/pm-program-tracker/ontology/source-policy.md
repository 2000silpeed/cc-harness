# PM 디자인 합성 입력의 권한

상태: 디자인 검토용 초안. 앱 구현·기획 승인·배포가 아니다.

## 권한 순서

1. 상위 `spec-fixed.md`의 합의 요구사항과 사용자의 현재 디자인 탐색 요청.
2. Design Ontology Harness의 체크섬 검증된 `docs/color-reference.md` 내 Semantic-os 그래프.
3. 이 폴더의 저작한 개념·레이아웃·컴포넌트 계약과 생성 토큰.
4. 사용자가 제공한 Digital Atelier 텍스트 샘플의 참고 가능한 표면·밀도 방향.

원본 요구사항의 P01–P04는 미승인 제안이다. 합성할 수 있는 것은 검토용 디자인이지 미승인 동작의 구현이 아니다. 기존 PM 문서와 승인 표시는 변경하지 않는다.

## 샘플에서 유지·변환·제외할 것

| 샘플                                             | PM 적용 판단                                                            |
| ------------------------------------------------ | ----------------------------------------------------------------------- |
| Soft Minimalism, tonal layers, restrained accent | 유지: 차분한 작업면과 절제된 주 액션                                    |
| TIL, 개인 아카이브, 태그 칩                      | 제외: 프로그램 관리 도메인으로 바꾸고 태그 기능을 만들지 않음           |
| 비대칭 에디토리얼, 56px 제목                     | 변환: 목록과 간트의 동일 행 정렬, 작은 작업 제목                        |
| 구분선 전면 금지                                 | 변환: 영역은 배경 차이, 날짜 격자·포커스·입력 경계는 기능적 예외        |
| 1.4rem 목록 간격                                 | 변환: 조밀한 데이터 행에 22.4px gap을 강제하지 않음                     |
| Inter 전용, 영문 대문자 라벨                     | 변환: 한글 대체 서체와 숫자 정렬, 한글 라벨 변형 금지                   |
| 유리 효과·CTA gradient                           | 기본 제외: 불투명 작업면·단색 액션을 우선하고 대비가 검증된 경우만 예외 |
| 15% ghost border                                 | 입력의 유일한 경계로 사용하지 않음; 배경과 실측 대비를 따로 검사        |

샘플 HEX는 최종 팔레트의 권한이 아니다. 유료 레퍼런스의 원문·이미지·조합표를 복제하지 않는다. 필요한 컬러 ID·역할·출처·실측 대비만 추상화한다.

## 실행 경계

- 엔진: `/Users/sungwoon/ai-projects/design-ontology-harness`의 설치된 `.venv/bin/design-ontology`.
- 기존 로컬 KB만 사용. 크롤링·모델 API·이미지 생성·패키지 설치·원격 게시 없음.
- 팀 팩은 최초 합성 때 이 폴더에만 생성했으며, 현재 중복 plugins·agent-team 및 build는 외부 백업에 보존한다. 상위 프로젝트의 15개 스킬과 AGENTS·훅을 덮어쓰지 않는다.
- 합성 재개 시 엔진의 팀 절차를 읽고 PM 전용 팩을 재생성하거나 백업에서 복원한다. 기존 handoff의 해시가 현재 입력과 일치하는지 다시 확인한다. 다른 프로젝트의 handoff를 재사용하지 않는다.
- 생성 파일을 수동 보정하지 않는다. 미흡한 결과는 입력을 고친 뒤 다시 합성한다.
