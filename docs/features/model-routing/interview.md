## 승인과 비승인의 경계

- 승인됨: G1 확정 요구사항, G2 B안, G3 이번 포함·제외 범위.
- 승인됨: B안의 초기 역할 연결 `default_worker=Sol/medium`,
  `diagnostic=Astra/high`, `verifier=Sol/high`와 이슈당 diagnostic 1회 기본값.
- 승인되지 않음: G4 이슈 목록·AC·의존성, G5 계약·시나리오.
- 승인되지 않음: 자동 루프 실행 위임, 구현, 커밋·push·외부 변경.
- 관찰되지 않음: 실제 실행 backend의 model/effort metadata. 요청값과 실제 관찰값을 분리한다.

## 회고

- AI 추천과 다르게 선택한 내용: 기록된 차이 없음.
- 새로 발견한 경계·예외: 모델 capability와 하네스 capability를 분리하고, 모델 변경이나 새
  컨텍스트가 retry/escalation counter를 초기화하지 않게 해야 한다.
- 다시 시작한다면 바꿀 접근: 현재 승인 기록으로 판단할 수 없는 새 질문을 만들지 않는다.
